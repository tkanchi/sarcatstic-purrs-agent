# Milo reference assets

This automation requires two binary image files in this folder:

- `milo_collage.jpg` — **primary** Milo source of truth
- `milo_profile.jpg` — supplementary reference

Use the SARCATSTIC PURRS Milo reference collage and profile image supplied with the project package.

Do not substitute or redesign Milo. The generation script intentionally fails when these assets are missing.
