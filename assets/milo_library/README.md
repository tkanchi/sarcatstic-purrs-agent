# Approved Milo Illustration Library

Place only user-approved transparent Milo PNG cutouts in this folder.

Recommended naming:
- milo_001_side_eye.png
- milo_002_sleepy.png
- milo_003_laptop.png
- milo_004_meeting_tired.png
- milo_005_manager_side_eye.png
- ...
- milo_050_driving_annoyed.png

Rules:
- one Milo per PNG
- transparent background
- no quote text
- no footer
- no watermark
- preserve Milo's locked gray-and-white appearance, amber eyes, gold right-ear hoop, yellow collar and paw-print tag
- props are allowed when they support the joke

The automation can rotate through these files automatically. Later, specific quotes can be mapped to a specific filename using an `illustration` field in the content file.
